## Pre-requisites

You need Python >=3.11 on your machine to install `gamma-lake`.

## Install with `pip`

```bash
pip install gamma-lake
```

The wheel contains the Rust core as a compiled extension.

## Install with `conda`

```bash
conda install gamma-lake --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `gamma-lake` from source](Build-from-Source).
