# API Reference

Each language's API is documented with its source:

| Language | Entry point                                                 | Reference                                                            |
| :------- | :---------------------------------------------------------- | :------------------------------------------------------------------- |
| Python   | `gammalake.GammaFeatureLake`, `gammalake.native.NativeLake` | Docstrings, shown by `help(GammaFeatureLake)` and `help(NativeLake)` |
| Rust     | `gamma_lake::Lake`                                          | `cargo doc --open` in `rust/`                                        |

[Native Engine](Native-Engine) describes how the languages share the Rust core, and the
[README](https://github.com/Point72/gamma-lake#core-api) summarises the Python API.
