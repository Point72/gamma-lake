## Setup

Follow GitHub's [forking workflow](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks)
to create a fork, configure remotes and authenticate. Then follow
[Build from Source](Build-from-Source) to install the development environment.

## Guidelines

Before opening a pull request, ensure that [lints](Build-from-Source#lint-and-autoformat) and
[tests](Build-from-Source#testing) pass. Squash commits into logical units and sign them with `-s`
to certify the [Developer Certificate of Origin](https://en.wikipedia.org/wiki/Developer_Certificate_of_Origin).

Use a [draft pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests#draft-pull-requests)
for unfinished work. Discuss large changes with the maintainers before implementation.
